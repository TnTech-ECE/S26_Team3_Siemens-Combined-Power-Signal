  \begin{block}{Abstract}

    This project aims to design a bias tee in such a way that a $2.5\ MHz$ clock signal, $200\ kHz$ communication signal, and $100\ W$ at $48\ V$ DC can be transmitted up to $10 m$ using a single coaxial cable from a transmitting board (Tx) to a receiving board (Rx). A function generator is used to generate a $2.5\ MHz$ sine wave that acts as the clock. The system utilizes the bias tee and other various filtering techniques to allow transmission of the desired signals. Additionally, after the signals are received on the Rx board, they are amplified using an op-amp, fed into a comparator that converts the sine wave signal to a square wave that a Phase Locked Loop (PLL) IC, the Si5345, can use as a reference to generate a 25 MHz clock signal as well as a 2.5 MHz clock signal to compare the signal generation to the output clock. Unfortunately, due to difficulty with assembly, we were unable to utilize the PLL IC.

  \end{block}

  \begin{block}{Design}
    The design is split up into five subsystems: the Bias Tee, IC Power, Clock and Jitter Measurements, Cable, and Communications. The subsystems combined on a custom PCB. There are three main components to this project: 1.) Bias Tee circuit for coupling/decoupling AC signal with DC power including simulations and component selection; 2.) Use of jitter cleaning PLL to measure high-fidelity jitter measurements; 3.) Back-Channel communications path for debugging/troubleshooting system synchronization messages.

    \vspace{0.3em}
    {\large\bfseries\color{structure} Bias Tee}\par
    The bias tee subsystem is responsible for the combination and separation of the power, clock, and communications signals. The design is made up of three steps of filtering reflected on the receiving and transmitting sides. On the transmitting side, a Butterworth filter is used to combine the clock and comms signals, a Bandstop filter set to the comms signal frequency is used to prevent the comms signal from bleeding onto the clock signal is used to, and the bias tee filter combines the clock and comms signal with the power signal. Then, the filtering occurs in the opposite order on the receiving side to isolate each signal again.

  \begin{block}{Results}

    \sectionHeading{Experimental Setup}

    \begin{itemize} 
      \item \textbf{MNIST} is a well known problem in machine learning
      \item MNIST Consists of 60000 training images of handwritten digits and 10000 test images
      \item The experiment proves the model \textbf{learns and converges} to a solution in a multi-output, large input environment
      \item The INN model was implemented in \textbf{Tensorflow}
      \item Interneurons were only applied to the hidden layer
      \item All other values for the interneuron ANN were the same as the principal cell ANN
      \item The principal cell ANN and interneuron ANN were optimized simultaneously using backpropogation
    \end{itemize}

    \sectionHeading{Experimental Results}

    \begin{itemize} 
      \item The INN \textbf{outperformed} the ANN
      \item The performance of the ANN as applied to the test set was $96.9$
      \item The performance of the \textbf{INN} was $97.2$
      \item The model has been shown to \textbf{converge and perform} better than the naive case
      \item The INN did not outperform the ANN \textbf{more} most likely due to the problem domain
      \item The power fo the INN is believed to be the abilit to \textbf{dynamically contextualize}
    \end{itemize}


  \end{block}

  \begin{block}{Future Improvements}

    \sectionHeading{Neuroscience}

    Neuroscience has not been able to make a definitive assertion about \textbf{interneuron input feature selection}, we intend to provide an \textbf{answer using this model}. We have chosen a Gen 2 framework because more is computationally known in this domain. The hope is that through the isolation of variables an answer will be approximated.

    \sectionHeading{Multi-Task and Transfer Learning}

    The literature review was rich with similar work in \textbf{multi-task learning}. It is hoped that by training the principal ANN weights with unity interneuron ANN weights, the special case of INN backpropagation, the principal cell ANN will converge to task 1 and allow the interneuron ANN to \textbf{learn task differentiation}. A similar idea can be applied to experiment with \textbf{transfer learning}.

  \end{block}
